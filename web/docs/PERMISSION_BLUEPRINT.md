# NovaHub Permission Blueprint

## Role Hierarchy

1. Founder
2. Super Admin
3. Admin
4. Moderator
5. Support

---

## Permission Types

- View
- Create
- Edit
- Delete
- Manage

---

## Modules

- Dashboard
- Users
- Wallet
- Transactions
- Orders
- Platforms
- Categories
- Services
- API Providers
- API Services
- Support
- Broadcast
- Statistics
- Settings
- Admin Management
- Permission Management
- Audit Log

---

## Rules

- Founder has full access.
- Every permission is assigned per module.
- Hidden modules are not visible in Admin Panel.
- All critical actions are stored in Audit Log.
